# Implementation Plan: UI Polish for Aurora

**Date:** 2026-11-17  
**Goal:** Elevate Aurora's UI from an MVP prototype to a delightful, highly polished toddler game with modern rounded typography, audio mute controls, animated micro-interactions, responsive candy-style cards, confetti celebration, and rewarding game feel.

---

### Task 1: Typography & Global Styling Foundation
- **Files**: `index.html`, `src/styles.css`
- **Actions**:
  - Load Google Font `'Fredoka'` (weights 400, 600, 700, 800) in `index.html`.
  - Update `font-family` in `src/styles.css` to use `'Fredoka'`.
  - Add lively color variables, enhanced drop shadows, safe-area padding improvements, and bouncy button transitions.

### Task 2: Audio Control & Mute Toggle
- **Files**: `src/game/audio.js`
- **Actions**:
  - Add `isMuted()`, `setMuted(muted)`, and `toggleMute()` functions.
  - Check mute status before scheduling any oscillator tone.
  - Persist mute state in `localStorage` under `aurora-sound-muted`.

### Task 3: Interactive Header, Mute Controls & Idle Mascot Animation
- **Files**: `src/ui/screens.js`, `src/styles.css`
- **Actions**:
  - Add a persistent top bar / sound toggle (🔊 / 🔇) to Menu and Game headers.
  - Add `@keyframes owlFloat` for gentle breathing/wobble on the owl mascot.
  - Style header with responsive pill badges.

### Task 4: Game Feel, Snapping Animations & Particles
- **Files**: `src/game/dragdrop.js`, `src/styles.css`
- **Actions**:
  - Update target styling with clean pastel borders and hover glow.
  - Add snap bounce animation (`transform: scale(1.18) -> scale(1)`) on target placement.
  - Increase particle variety and add random rotation to sparks.

### Task 5: Level Select Grid & Progress Counter
- **Files**: `src/ui/screens.js`, `src/styles.css`
- **Actions**:
  - Add progress summary bar (`X / 30 Cleared · ⭐ Y Stars`) at the top of World screen.
  - Style level cards with soft candy cards, glowing next-level ring, and polished star badges.

### Task 6: Victory Screen & Confetti Celebration
- **Files**: `src/ui/screens.js`, `src/styles.css`
- **Actions**:
  - Implement full-screen confetti animation on level completion.
  - Add staggered star pop-in animation on victory dialog (`⭐ ⭐ ⭐`).
  - Add "Next Level" primary emphasis button.

### Task 7: Build Verification & Git Commit
- **Actions**:
  - Run `npm run build` to verify clean compilation.
  - Inspect bundle and commit changes to `main`.
